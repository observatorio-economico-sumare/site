# Histórico da versão 4

O arquivo docs/mvp_v4_referencia.html reproduz o protótipo visual recebido em 23/10/2026.
Os números e a distribuição setorial do protótipo são **não certificados** na etapa técnica inicial.
A interface operacional utiliza placeholders até a validação em fontes primárias.
A inclusão de uma referência a fonte no protótipo não significa que o código da consulta, a metodologia ou o valor foram auditados.
