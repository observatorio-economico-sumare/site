# Observatório Econômico de Sumaré (OES)

Projeto independente, apartidário e gratuito para divulgação de indicadores econômicos e sociais de Sumaré (SP).

## Estado

**Etapa 1: estrutura técnica em desenvolvimento.** Indicadores devem ser confirmados com fontes e metadados oficiais antes da divulgação pública. O projeto permanece privado nesta fase.

## Arquitetura

- HTML, CSS e JavaScript para interface estática.
- Python (biblioteca padrão) para validar e preparar os indicadores.
- GitHub para histórico, código e auditoria.
- GitHub Actions para verificações; GitHub Pages somente quando autorizado.

Dados não validados não poderão aparecer como confirmados. Nunca versionar credenciais, tokens ou informações pessoais.

A documentação da etapa 1 acompanhará o código.
